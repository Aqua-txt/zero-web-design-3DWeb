# 《棂间叠珠》美术设计方案 v1

> 一句话概念：**夜读灯下，一只紫檀棂笼里，七宝珠相叠相合；光从棂条间漏出来，珠影落在案上。**
>
> 关键词：宋明书斋 · 紫檀多宝格 · 冰裂纹窗 · 绢纱宫灯 · 珠光 · 朱砂印 · 留白

本文只谈美术与呈现方案，不改动现有物理、合成判定、计分与操作逻辑。所有场景、珠子、容器均以 three.js 程序化建模，不引入外部模型 / 贴图 / HDR（仅允许引入一套开源中文字体）。

> 实现说明：最终落地版以 `src/` 代码为准。绢面透明度、棂条密度、Bloom 强度与光源强度按屏幕可读性做过微调；整体色板、结构与七宝体系保持不变。

---

## v3 现状：秋夜庭院（当前实现）

舞台由 v2 的**白昼庭院**换成**秋夜庭院**，做法是把一份独立的「庭院秋夜」微缩场景（three.js + Bloom 的单独 demo）整段移植进项目。

### 分工

| 模块 | 内容 |
| --- | --- |
| `src/art/nightCourt.ts` | 移植的环境：夜空 shader、1100 颗星、月亮、PMREM 环境反射、月光/半球光/檐下暖灯、坡屋顶、院墙与大门、门口一对石狮、月洞门、正房与厢房及室内陈设、石径、枫/银杏/竹、太湖石、水缸、灯笼火盆、落叶、飞尘、炊烟、`UnrealBloomPass` 后处理；含可开合的大门（`setGateOpen`）与迎门影壁的红底金字「福」贴图 |
| `src/art/stoneSet.ts` | **保留**的石案一组：石桌（含两只石凳）、石灯笼与桌上柿子/茶盏，仍位于庭院中心 |
| `src/art/lantern.ts` | **保留**的紫檀棂笼与须弥座；棂笼坐在石桌面上 |

- 夜庭院整体挂在 `root` 上并下移到 `GROUND_Y`，使 diorama 地坪（y=0）与石桌、石凳、石灯笼的既有高度基准对齐；物理与落珠映射完全不受影响。
- 庭院整体放大 `COURT_SCALE = 2.7`：石桌与棂笼保持原尺寸，建筑与院子放大后不再显得「一只盒子塞满院子」；点光源的照射距离与强度按缩放补偿，月光阴影范围一并按比例放大。
- 石案一组在平面上再收一道 `STONE_PLAN = 0.82`（只压 XZ，桌面高度 `TABLE_TOP` 不动，棂笼照样坐得住），石凳、石灯笼、桌上摆件随桌面一起收；猫与鸟的锚点用同一个比例换算，避免站位错开。
- 棂笼平面收窄 `BOX_PLAN = 0.82`（`lantern.ts` 里对整组做 `scale.set(BOX_PLAN, 1, BOX_PLAN)`），物理侧新增 `BOX_HALF_XZ`：水平限制用它、竖直仍用 `BOX_HALF`，所以须弥座照旧坐在桌面上、底面与物理底盘仍然对齐。桌上柿子盘与茶盏再各自缩 0.86（只缩几何、不动位置），与须弥座之间留出清楚的间隙。7 号珠仍可通过斜向合成（两球中心距上限 ≈3.3 > 直径和 3.12）。
- 开场运镜的关键帧写在**庭院本地坐标**里（`courtToWorld()` 统一换算），改庭院尺寸时不用再手改一整套机位。
- 开场运镜在 `scene.ts`：全景 → 推近大门 → `setGateOpen()` 开门 → Catmull-Rom 曲线绕影壁、穿月洞门 → 院内升起对准石案；镜头期间关闭 OrbitControls，落位后再交还操作权并允许落珠。
- 门口石狮：`nightCourt.ts` 里 `stoneLion(withBall)` 程序化拼出一对石狮（须弥座三段、后胯 + 前胸 + 肩三个球压出蹲坐量感、直立前腿与三趾爪、两圈卷毛鬃与鬃底盘、低眉小眼、方形鼻吻与阔口、身后卷尾），左雄踏绣球、右雌抚幼狮，整体放大 1.25 倍后蹲在门枕石上，`rotation.y` 略向门外侧转；与大门、门槛同属 `gateG`，随场景整体缩放。
- 月亮：天空 shader 里原有一轮月亮，但方向在镜头背后且仰角约 50°，实际一直看不到。现改为**西北天际、仰角约 10°**的满月（角径约 4°），并把开场全景的目标点抬高，使「起局」后的第一镜就能看到月亮；主光仍按更高的仰角布置，避免夜色里地面发黑。
- 时段可切换：`src/config.ts` 的 `TIME_OF_DAY` 决定初始时段，右上角「日 / 夜」按钮可在运行时切换并持久化到 localStorage。整套参数集中在 `nightCourt.ts` 的 `STAGE` 表里（背景、雾、天空色标、发光体方向、主光、半球光、补光、环境反射贴图与强度、Bloom、灯火系数、曝光），切换时逐项重配；天空 shader 的色标与渐变曲线都由 uniform 注入，昼夜共用同一份着色器。
- 白天太阳与夜里月亮都挂在约 10° 的低仰角（西北天际），开场全景抬头可见；主光另取更高仰角，避免地面整片背光发黑。
- 移植时删去 demo 自带的石桌、石凳与石灯笼，避免与保留的那一组重复。
- 相机改为「站在主庭院内、越过石桌看向正房」，并给石案补一盏柔和顶光，保证夜色下石桌/石凳/石灯仍可读。
- demo 的相机入场动画、自建 renderer/controls 与 `ResizeObserver` 均已剥离，只保留可注入 `scene`/`renderer`/`camera` 的 `createNightCourt()`。

## 1. 世界观与视觉原则

**情境**：一间宋明风格的书斋，入夜，案上点着灯。主角不是水果，而是一只**棂笼**——紫檀做框、铜活包角、四面糊绢、棂条作冰裂纹的灯箱式多宝格。七种「宝珠」从上方落入笼中，同色相叠、合而为大；最终两枚夜明珠相击，化为一室清辉。

**五条原则**

1. **珠亮、器沉、境退**：三层明度严格分开，珠子永远是画面最亮、最饱和的部分。
2. **光从器中来**：主光动机来自笼内灯火与窗外月色，不做无来源的棚拍光。
3. **棂影即纹样**：冰裂纹不是贴图装饰，而是会投在案面上的光影，也是全局视觉母题。
4. **动若珠落玉盘**：落珠有重量、碰撞有脆响、合成有一瞬的「光华」，但所有特效 ≤ 0.8s，不挡操作。
5. **留白与克制**：UI 只留纸、墨、朱砂、金四种语言；背景道具全部低对比、轻虚化。

**三层明度结构**

```
L2  珠     亮度 35–90%   高饱和 / 自发光 / 清晰锐利
L1  器     亮度 12–32%   紫檀近黑、古铜微光、边缘锐利
L0  境     亮度  4–14%   低饱和、强雾、虚化、只做剪影
```

### 3.3 机位

- 透视相机 `fov 42`，初始位 `(7.6, 8.6, 12.4)`，看向 `(0, -0.3, 0)`；笼体约占画面高 55–60%。

## 4. 容器「棂笼」

内腔严格等于现有物理盒 `BOX_SIZE = 6.667`（半边长 3.333），视觉件全部挂在盒外，不参与碰撞。

### 4.1 结构分解

| 部件 | 规格 | 材质 | 说明 |
| --- | --- | --- | --- |
| 四根立柱 | 0.16 × 0.16 × 7.4 | 紫檀 | 位于四角，向上出挑 0.3 形成灯笼罩骨架 |
| 上下横枨 | 0.16 × 0.14 | 紫檀 | 45° 拼角，接缝处压铜片 |
| 铜包角 | 0.18 立方，圆角 | 古铜 + 回纹錾刻 | 8 个角，`RoundedBoxGeometry` |
| 绢面 | 6.67 × 6.67，四片 | 素绢 | 透明度 0.10，双面，`depthWrite = false` |
| 冰裂纹棂条 | 截面 0.03 × 0.03 | 紫檀 | 四边各一组，合并为一个几何体 |
| 海棠开光 | 中心开窗 4.4 × 4.4 | — | 保证最大 4.0 直径的夜明珠不被遮挡 |
| 顶沿 | 0.16 宽，四边 | 紫檀 + 铜线 | 完全敞开，不设横梁，避免挡落珠 |
| 云头牙子 | 0.35 高，四角外挑 | 紫檀 | 只在顶沿外侧，避开落珠路径 |
| 须弥座 | 7.6 × 7.6 × 0.5 | 紫檀 + 铜包边 | 圭角 / 束腰壸门 / 上枋 |
| 内底 | 6.6 × 6.6 薄板 | 青玉 + 水波纹 | 顶面略低于 -3.333，避免与球穿插 |
| 内壁 | 四片 | 素绢暖色渐变 | 上暗下亮，把珠子衬出来 |
| 内灯盏 | 四角各一 | 古铜 + 火苗 Sprite | 只发光不投影 |

### 4.2 尺寸与穿模规避（重要）

物理层允许球心最多嵌入墙内 0.08，球面最多外凸至 `±(BOX_HALF + 0.08)`。因此：

- 绢面放在 `±(BOX_HALF + 0.10)`，棂条放在 `±(BOX_HALF + 0.13)`，木框内表面 `±(BOX_HALF + 0.16)`。
- 这样即使极限贴墙，球也只是「压近绢面」，不会穿出棂条。
- 底面视觉板顶面定在 `-BOX_HALF - 0.005`，球体最多压入 0.085，视觉上仍是「坐在玉板上」。
- 顶沿与云头不进入 `±BOX_HALF` 的立方体内，落珠永不撞框。

### 4.3 棂条纹样

- 外圈：**冰裂纹**（不规则多边形），用确定性随机生成 6–9 条折线，疏密有致；用 `ExtrudeGeometry` 或细长方体合并。
- 中央：**海棠形开光**（四瓣曲线），用 `Shape` + `holes` 挤出成牙板，厚度 0.04。
- 前、左、右三面开光更大（4.6），后壁最密（无开光），形成「前透后实」的层次。
- 棂条全部合并成每面 1 个 mesh，材质与木框一致；影子投在案面上。

### 4.4 光的两个小机关

1. **内灯**：笼内一盏点光 + 四角火苗 Sprite + 内壁底部暖色自发光，让珠子像浸在灯油光里。
2. **棂影光斑**：不真的用点光投影（六面阴影太贵），而是在案面铺一张 9 × 9 的加法混合平面，贴一张程序化冰裂纹光斑图，缓慢呼吸偏移。远看就是「灯从棂条里漏出来」，成本几乎为零。
3. 高画质可额外让主光真正穿过棂条，在桌面留下锐利投影；中低画质只保留光斑贴图。

### 4.5 近面淡出

相机绕到某一侧时，该侧绢面 + 棂条按视角点乘淡出到 0.04 透明度，保证永远看得见笼内珠子；淡出 0.25s 缓动，避免闪烁。

## 9. three.js 实现要点

### 9.1 模块划分

```
src/art/
  palette.ts    色板、等级视觉元数据（名称 / 主色 / 发光 / 材质 key）
  noise.ts      确定性随机、值噪声
  textures.ts   程序化贴图：木纹、纸纤维、绢纹、冰裂纹法线、金箔、光斑
  materials.ts  材质工厂：紫檀、古铜、绢、青玉、琉璃、蜜蜡、砗磲、紫晶、夜明珠
  nightCourt.ts 庭院环境（移植自「庭院秋夜」微缩场景）：院墙大门月洞门、正房厢房、树石水缸、天空 shader、星、日月、全天光与灯火、昼夜切换、开门动画
  stoneSet.ts   保留的石案一组：石桌 + 两只石凳、石灯笼、桌上柿子与茶盏
  creatures.ts  庭院生灵：石凳上的猫、桌沿小鸟、夜间萤火；react(level) 响应合成
  ink.ts        终局卷轴的水墨山水底纹（Canvas 2D）
  lantern.ts    棂笼：框、铜活、棂条、绢面、须弥座、内灯
  pearls.ts     珠几何、材质、光晕、穿线孔
  fx.ts         涟漪、金粉、光丝、冲击波、飘尘、落瓣；终局化光 ascend
  quality.ts    画质分级与自适应
```

环境与道具分成 `nightCourt` / `stoneSet` 两个模块，替换庭院时石案一组可以整体留下；`scene.ts` 只保留相机、控制器、渲染器与装配调用；`main.ts` 的物理与合成逻辑不动。

### 9.2 关键技术

- **环境反射**：搭一个极小的「灯房」场景（黑墙 + 两块暖/冷自发光面 + 几条灯带），用 `PMREMGenerator.fromScene()` 生成 envMap，比外部 HDR 更可控，也更符合夜景。
- **木纹 / 纸纹**：Canvas 512² 绘制，木纹用拉伸值噪声 + 细条纹，纸纹用三层噪点；`CanvasTexture` + `SRGBColorSpace`，全局复用。
- **冰裂纹**：Canvas 画折线 → 模糊 → Sobel 转法线；光斑另存一张 alpha 蒙版。
- **棂条**：`ExtrudeGeometry`（海棠开光牙板）+ 合并细长方体；按面合并，控制 draw call。
- **包角 / 框料**：`RoundedBoxGeometry` 做 0.01–0.02 倒角，避免 CG 感。
- **珠**：`SphereGeometry(r, 48, 32)` 共享；每级一个材质。高画质开 transmission，中低画质用 clearcoat + 菲涅尔假透光（差异 < 10%）。
- **后期**：高画质 `EffectComposer` = RenderPass + UnrealBloomPass（threshold .85、strength .35、radius .5）+ 自定义暗角/颗粒 Pass + OutputPass；中低画质直出。
- **阴影**：只让主光投影，2048（高）/ 1024（中）；`normalBias .02` 抑制棂条阴影 acne。
- **透明排序**：绢面 `depthWrite = false`、`renderOrder` 分层；珠子保持不透明。
- **确定性**：所有程序化随机用固定 seed，保证每次开局纹理一致。

### 9.3 性能预算

| 指标 | 高 | 中 | 低 |
| --- | --- | --- | --- |
| 分辨率 | DPR ≤ 2 | ≤ 1.5 | 1 |
| Draw call | ≤ 90 | ≤ 70 | ≤ 55 |
| 三角形 | ≤ 150k | ≤ 110k | ≤ 80k |
| 阴影图 | 2048 | 1024 | 关闭 |
| Bloom | 开 | 关 | 关 |
| transmission | 开 | 关 | 关 |
| 粒子 | 120 | 64 | 24 |

自适应：启动后采样 120 帧平均帧时，连续低于 50fps 自动降一档；用户可在设置里锁定画质（如需）。

### 9.4 兼容注意

- 现有 `aimRing`、`pop`、`dot` 等类名与 DOM 结构可保留，只改样式，减少回归。
- `LEVELS` 增加 `art` 字段（不改 `radius` / `score`），CSS 变量从同一处注入。
- `BEST_KEY` 建议改名，但需兼容旧存档（读旧 key 迁移一次）。
- 俯视图的配色、球影方向、光晕要与 3D 主光一致（右上光源）。

### 9.5 庭院生灵、昼夜与终局演出

- **昼夜切换**：`nightCourt.ts` 里集中一张 `STAGE` 表（`{ day, night }`），把背景色、雾、天空 shader 的全部 uniform、主光/半球光/补光、环境贴图、星星、灯火增益、火焰 sprite、Bloom、曝光都列进同一结构；`setTimeOfDay()` 逐项重配，运行时切换不重建场景。环境贴图用两张预烘的 `PMREMGenerator` 结果互换，避免切换时卡帧。天空 shader 色标、曲线与日月发光体全部 uniform 化，同一套 shader 同时服务白天与秋夜。
- **点光源缩放补偿**：庭院整体放大 2.7 倍后，`PointLight.decay = 2` 会让照度按平方衰减，故灯火强度统一乘 `LIGHT_GAIN = COURT_SCALE²`、照射距离乘 `COURT_SCALE`，闪烁动画里也要乘，否则切时段后灯会变暗。
- **生灵**：猫用胶囊 + 球拼出蹲坐姿态（头、耳、胸腹、四足、长尾），呼吸与甩尾是低频正弦，眨眼按随机间隔缩放眼睑；夜间把眼睛材质的自发光与瞳色提到琥珀。小鸟是缩小的胶囊 + 锥形尾羽。萤火是单个 `Points`，位置、相位、闪烁频率写进 attribute，在顶点着色器里做正弦明灭与缓慢漂移，靠 `AdditiveBlending` 叠出柔光，数量按画质分级。
- **生灵看戏（玩法联动）**：`Creatures.react(level)` 记录「受惊时刻 + 级别」，各部件在之后 1.6s 内按 `1 - t/1.6` 衰减地做出反应——猫抬头（`headPivot.rotation.x` 到 −0.31）、竖耳（×1.22）、尾节鼓起（小合成 ×1.28、6 号以上 ×1.75）、6 号以上额外蹦 0.09；小鸟只对 4 号以上起飞，0.9s 内沿正弦弧线抬升 0.42 并前倾扇翅，两只错开 0.09s；萤火把 `uKick` 送进顶点着色器，座标向原点收拢、亮度 ×2.3，1.2s 内按平方衰减。猫的各个部件收在一个 `inner` 组里，蹦跳只动 `inner.position.y`，不影响世界坐标。
- **七宝谱**：`main.ts` 里的 `codex`（Set）+ `CODEX_KEY = 'lingjian-codex'` 持久化，`spawnBall()` 末尾统一调 `recordPearl(level)`，所以不管是落的珠还是合成的珠都会记谱；首次记录触发 `sfx.codex(level)`（按等级升调的清磬）与谱下方的短笺，谱上对应的点播一次 `ladder-stamp` 落印动画；集齐七枚走 `sfx.codexComplete()` + 闪屏 + 「七宝齐辉」。图鉴面板由 `renderCodex()` 从 `LEVELS` + `CODEX_LORE` 现生，未识条目灰显并以 `？` 占位。
- **终局化光**：`fx.ascend(positions)` 记录当前珠位后生成一批上升光点（带漩涡与淡出）、中心 flash 与一圈金环；`main.ts` 在调用后延时 ~1.1s 再展开卷轴，让「珠子升空」和「卷轴落下」有先后节奏。
- **水墨卷轴**：`ink.ts` 的 `drawInkScroll(canvas)` 把 `src/assets/ink-scroll.png`（远山、飞鸟、红日、小舟）按「宽度铺满、垂直居中」画进画布，尺度取自 `canvas.clientWidth/Height × DPR`，任何屏幕比例下都不变形；画完再叠一层「中心浓、边缘散」的宣纸雾，保证正文压在墨上也读得清。图片未解码时用同文件里的 `drawFallback()`（纯 Canvas 现画远山 + 淡月 + 朱印）兜底，解码完成后自动重画所有等过的画布。卷轴展开那一刻才量尺寸，所以 `main.ts` 在 `over.hidden = false` 之后又重画一次。
- **最后十秒**：`config.ts` 的 `DANGER_SECONDS = 10`；`#danger` 层（`z-index: 8`，在 HUD 之下、场景之上）以径向渐变铺出残阳红晕，`.on` 时按 `danger-beat` 1s 心跳；`tickTimer()` 每跨一个整秒调 `sfx.warn(second)`（末三秒换更高更响的木鱼），收局与重开都会摘掉 `.on`。

## 11. 风险与备选

| 风险 | 对策 |
| --- | --- |
| 棂条遮挡珠子 | 开窗 4.4–4.6、前疏后密、近面淡出 |
| 暖光让蓝紫珠发灰 | 主光偏中性（4300K）、冷边光提亮、蓝紫珠加自发光 |
| Bloom 把小珠糊成一团 | 阈值 .85、只让自发光与高光溢出 |
| transmission 性能 | 分档关闭，假透光兜底 |
